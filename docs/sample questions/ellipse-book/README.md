# Ellipse textbook pages: the corpus for the ellipse lessons

The operator's textbook pages on the ellipse, sent in chat on 2026-10-30 for the lessons that start on 14 Nov 2026. Exercise numbers restart on each page (each page is a different section of the book), so an exercise is cited as `p<page>-<number>`, e.g. `p10-9`.

| Page | What it holds |
|---|---|
| 01 | The ellipse from its givens: axes, distance between the foci, a point, a focus, a vertex's distance from a line |
| 02 | The major axis on the y-axis; points at given focal distances; a line parallel to the x-axis; two ellipses |
| 03 | A chord through a focus; a diameter of given length and its conjugate |
| 04 | A rhombus inscribed in an ellipse; a circle cutting it in four points; a tangent's slope |
| 05 | A rhombus whose vertices are foci and vertices; an equilateral triangle and a 13-14-15 triangle inscribed |
| 06 | An ellipse by stretching a circle's coordinates; an inscribed rectangle; a vertical line cutting both curves |
| 07 | Translating a circle, then scaling it; the focal-distance sum |
| 08 | The mutual position of a line and an ellipse, with and without a parameter k |
| 09 | Loci that are ellipses: a distance ratio, sums of squared distances, two moving lines |
| 10 | The locus from a tangent's length; a figure built from a point P on the ellipse |
